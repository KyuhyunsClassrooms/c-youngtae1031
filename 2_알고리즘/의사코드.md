# 2. 알고리즘 (의사 코드) (10점)

## 1. `main` 함수의 전체 흐름
```
시작
 난수를 초기화
 플레이어 초기 설정
 라운드 = 1

 반복 (게임을 그만둘 떄까지)
 라운드 시작
 승리시 라운드 + 1
 패배 하면 반복 종료
 다시 하시겠습니까? (1예,:0아니요)" 출력
 사용자가 0입력 하면 반복을 종료
 반복 끝
  게임을 종료 합니다 출력
종료
```

## 2. 핵심 기능 1: 라운드 전투 실행 함수
```

시작
   슬라임 능력치 초기화
   플레이어의 방어 상태와 중독 상태 초기화

   ==전투 시작== 출력

   반복 (플레이어의 HP > 0 AND 슬라임 HP > 0):
        현제 체력 상태를 출력
        행동 매뉴 선택을 줄력
        플레이어 행동 입력 받기 (action)

        만약 action이 공격이면:
            공격 피해를 계산하여 슬라임 HP감소
        만약 action이 방어면:
            다음턴 받을 피해 감소 설정
        민약 action이 회복이면:
            포션이 있으면 회복
            아니면 "퍼션 없음"을 출력
        만약 action 스킬이면:
            일정 확률로 슬라임에게 중독 아태 부여

        만약 슬라임의 HP가 0 이하면 ;
            "승리" 출력
        반복 종료
    반복 끝
종료
```

## 3. 핵심 기능 2: 플레이어 행동 처리 함수
```
시작
    플레이어 행동 선택 메뉴 출력
    플레이어 행동 입력 받기(action)

    만약 action 1(공격) 이라면:
        공격 피해 계산
        슬라임 HP를 피해만큼 감소
        피해량 출력
    
    만약 action 3(회복) 이라면:
        플레이어의 HP를 일정량 회복
        포션 개수 1 감소
        "회복했습니다." 출력
       아니면 
        "포션이 없습니다." 출력

    만약 action 4(스킬)이라면:
        일정 확률로 슬라임에게 중독 상태 부여
        중독이 성공하면:
            슬라임의 중독 턴 수를 3으로 설정
            "슬라임이 중독되었습니다" 출력
        실패하면
            "스킬을 실패했습니다" 출력 
종료

## 3. 핵심 기능 3: 슬라임 능력치 초기화 함수
시작
    기본 슬라임 능력치 설정
        최대 HP = 40
        공격력 = 8
        방어력 = 3

    현재 난이도에 따라 능력치 조정
        만약 난이도가 EASY이면:
            최대 HP를 조금 줄이고 (예: -5)
            공격력을 조금 줄인다
        만약 난이도가 HARD이면:
            최대 HP를 조금 늘리고 (예: +5)
            공격력을 조금 늘린다

    현재 라운드에 따라 능력치 강화
        라운드가 2 이상이면:
            라운드마다 최대 HP를 조금씩 증가 (예: 라운드당 +5)
            라운드마다 공격력을 조금씩 증가 (예: 라운드당 +1)

    슬라임의 현재 HP를 최대 HP로 설정
    슬라임의 방어 상태와 중독 상태를 0으로 초기화
종료
